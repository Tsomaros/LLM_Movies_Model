# LLM Movie Predictor: Roadmap

Spec: `docs/superpowers/specs/2026-11-05-llm-movie-predictor-design.md`

The spec covers five subsystems that build on each other. Each phase gets its own detailed plan, written when the
previous phase is finished, because later phases depend on facts learned on the way (the base model and its cutoff,
the vote threshold, data coverage).

| Phase | Plan | Delivers | Decisions it unlocks |
|---|---|---|---|
| 1 | `2026-11-05-phase1-foundation-and-data.md` | Repo, CI, form contract, TMDB + Wikidata pull in Colab, cleaning, SQLite, leak-safe computed inputs, prompts, private HF dataset, data report | Minimum vote count for score; field coverage |
| 2 | `2026-11-10-phase2-model-and-training.md` | Base-model shortlist check (licence, cutoff), memorization probe, quantile-head model, training loop with Hub checkpoints, Kaggle/Colab launchers, W&B, experiments E1–E3 on samples | Base model and size; clean-holdout dates |
| 3 | written after Phase 2 | Conformal calibration, neutral placeholders, batched effects, writer adapter, faithfulness check | Explanation templates |
| 4 | written after Phase 3 | Baselines B0–B2, read-only LightGBM scoring of shared films, one-time test run on both test sets, final all-years model, report, HF model card | — |
| 5 | written after Phase 4 | FastAPI service, 8-bit model, Docker Space, React + Vite form and results page, latency fallbacks | Merge into the app (decided at the end) |
